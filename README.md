## Go Example

The example program is in [main.go](main.go). It prints a short profile summary and a timestamp.

### Run

```bash
go run .
```

### Build

```bash
go build -o app.exe .
```

```text

Focus: backend services and clean architecture
Generated: 2026-03-16T12:00:00Z
```
